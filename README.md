# ExcaSimulator

Meta Quest 3에서 플레이하는 굴착기 VR 시뮬레이터입니다. 렌더링은 노트북(RTX 5070)이 하고, Quest 3는 Quest Link로 화면과 컨트롤러 입력만 담당합니다. 엔진은 Unreal Engine 5.8입니다.

## 개발 계획

1. **기술 검증 프로토타입** (현재 단계): 굴착기 관절·스틱 조작, 흙 파기, 벽 파괴, VR 성능 확인
2. **튜토리얼 모드**: 관절별 조작, 조합 동작, 주행, 안전 규칙을 단계별로 훈련
3. **시나리오 2개 (1인용)**: 트렌칭, 데몰리션
4. **2인 LAN 대전**: 노트북 2대, 작업 시간 + 안전 감점으로 승부
5. **데모 다듬기**: 실제 3D 모델, 조명, 사운드, 진동, 최적화

## 1단계 프로토타입에 들어있는 것

에디터에서 만들어야 하는 에셋 없이, 전부 C++ 코드와 엔진 기본 도형으로 만들었습니다. 실제 모델은 5단계에서 바꿉니다.

| 클래스 | 하는 일 |
|---|---|
| `AExcavatorPawn` | 하부 주행체, 선회, 붐·암·버킷 관절, 운전석 VR 카메라, 흙 담기·쏟기 |
| `ADigTerrain` | 32 m × 32 m 변형 가능 지형 (20 cm 격자). 버킷으로 파면 깎이고, 쏟은 흙은 안식각 34°로 쌓임 |
| `ASoilClump` | 버킷에서 쏟아지는 흙덩이 (물리). 바닥에 멈추면 지형으로 합쳐짐 |
| `ABrickWall` | 물리 벽돌 203개로 쌓은 6 m × 2.8 m 벽 (데몰리션 테스트용) |
| `AExcaGameMode` | 굴착기를 플레이어로 지정하고, 지형과 벽이 레벨에 없으면 생성 |

## 노트북에서 처음 실행하기

### 준비물

- Unreal Engine 5.8.4 (Epic Games Launcher)
- Visual Studio 2022, 설치 항목: "C++를 사용한 게임 개발" 워크로드
- Meta Quest Link 앱 (PC용), USB-C 케이블 (Air Link도 가능하지만 처음엔 케이블 권장)

### 순서

1. 저장소를 받습니다: `git clone https://github.com/hsahn72/ExcaSimulator.git`
2. `ExcaSimulator.uproject`를 우클릭해서 **Generate Visual Studio project files**를 누릅니다.
3. `ExcaSimulator.uproject`를 더블클릭합니다. "모듈을 다시 빌드할까요?"가 나오면 **예**를 누릅니다. 몇 분 걸립니다.
   - 빌드가 실패하면 `ExcaSimulator.sln`을 Visual Studio로 열고 `Development Editor` / `Win64`로 빌드한 뒤, 오류 메시지를 알려주세요.
4. 에디터에서 **File > New Level > Basic**으로 새 레벨을 만듭니다.
   - 아웃라이너에서 **Floor**를 삭제합니다. 지형이 그 자리에 생성됩니다.
   - **PlayerStart**가 없으면 Place Actors 패널에서 하나 추가하고 위치를 (0, 0, 100)으로 둡니다.
   - `Content/Maps/Proto`로 저장합니다.
5. **Edit > Project Settings > Maps & Modes**에서 Editor Startup Map과 Game Default Map을 `Proto`로 지정합니다.
6. 키보드로 먼저 확인: 툴바의 Play(▶)를 눌러 아래 키보드 조작이 되는지 봅니다.

### Quest 3로 실행하기

1. Quest Link 앱의 **설정 > 일반**에서 **OpenXR 런타임**을 Meta Quest Link로 지정합니다.
2. Quest 3를 케이블로 연결하고, 헤드셋에서 **Quest Link**를 켭니다.
3. 에디터 툴바 Play 옆 ▼ 메뉴에서 **VR Preview**를 누릅니다.
4. 의자에 앉아 정면을 보고 오른손 **A 버튼**을 눌러 운전석 위치를 맞춥니다. (시작 1초 후 한 번 자동으로 맞춥니다.)

## 조작법 (ISO 방식)

| 입력 | Quest 컨트롤러 | 키보드 |
|---|---|---|
| 선회 좌/우 | 왼쪽 스틱 좌/우 | A / D |
| 암 펴기/당기기 | 왼쪽 스틱 앞/뒤 | W / S |
| 붐 내리기/올리기 | 오른쪽 스틱 앞/뒤 | ↑ / ↓ |
| 버킷 오므리기/펴기 | 오른쪽 스틱 좌/우 | ← / → |
| 주행 모드 (누르고 있는 동안) | 왼쪽 그립 | Shift |
| 주행 모드에서 좌/우 궤도 | 왼쪽 스틱 앞뒤 / 오른쪽 스틱 앞뒤 | W·S / ↑·↓ |
| 운전석 위치 다시 맞추기 | A 버튼 | R |
| 처음부터 다시 | B 버튼 | Backspace |

게임패드(Xbox 패드)도 같은 배치로 동작합니다.

## 1단계에서 확인할 것

- [ ] 빌드와 VR Preview 실행이 되는가
- [ ] **프레임**: 콘솔(`~`)에 `stat unit`을 입력하면 노트북 화면의 미러 창에 표시됩니다. Quest 3 72 Hz 기준 Frame 13.9 ms 이하, 90 Hz 기준 11.1 ms 이하가 목표
- [ ] 스틱 조작 방향이 실제 굴착기 감각과 맞는가, 속도는 적당한가
- [ ] 흙을 파서 버킷에 담고, 버킷을 펴면 흙이 쏟아져 쌓이는가
- [ ] 벽돌 벽을 버킷이나 붐으로 밀면 무너지는가, 이때 프레임이 떨어지는가
- [ ] 선회할 때 VR 멀미가 심한가

속도, 관절 각도 한계, 버킷 용량 같은 값은 굴착기 Pawn의 Details 패널 `Excavator` 카테고리에서 바꿀 수 있습니다.

## 알려진 한계 (다음 단계에서 개선)

- 굴착기는 물리 시뮬레이션이 아닌 키네마틱 방식이라, 땅이나 벽에 막히지 않고 통과합니다. 버킷이 가득 차면 더 파지지 않고 땅을 통과합니다.
- 굴착기는 지형의 기울기를 따라 기울지 않고 높이만 따라갑니다.
- 모양은 상자로 만든 임시 모델입니다.
- 손 컨트롤러 모델과 운전석 레버는 아직 표시되지 않습니다.
